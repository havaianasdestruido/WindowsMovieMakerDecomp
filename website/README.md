# WindowsMovieMakerDecomp — Documentation Site

This directory contains the project's [Docusaurus](https://docusaurus.io/) documentation
site: a full-codebase documentation set covering the Windows Live Movie Maker 2012
(Sundance) source reconstruction — getting started, architecture, all 29 build-target
modules, testing, methodology, tools, and reference material.

## Prerequisites

- Node.js **≥ 18** (Node 20/22 recommended)

## Running locally

```bash
cd website
npm install        # first time only

npm start          # dev server with hot reload → http://localhost:3000/WindowsMovieMakerDecomp/
```

The dev server opens the site at the configured `baseUrl`
(`/WindowsMovieMakerDecomp/`).

## Production build

```bash
npm run build      # static site → website/build/
npm run serve      # serve the production build locally
```

## Structure

```text
website/
├── docs/                  # The documentation pages (MDX/Markdown)
│   ├── intro.md           # Introduction
│   ├── getting-started/   # Requirements, build, run, verify, troubleshoot
│   ├── architecture/      # Overview, app flow, module map, engine internals
│   ├── modules/           # One page per build target (29 modules)
│   ├── testing/           # Contract suite, harnesses, TODO audit
│   ├── methodology/       # Reconstruction, stub design, quirks, analysis
│   ├── tools/             # Build & analysis tooling
│   └── reference/         # Repo map, SDK compat, conventions, security, glossary, FAQ
├── src/
│   ├── pages/index.js     # Custom landing page
│   └── css/custom.css     # Theme + landing page styles
├── static/img/            # Logo & favicon
├── docusaurus.config.js   # Site configuration
└── sidebars.js            # Autogenerated sidebar config
```

The sidebar is **autogenerated** from `docs/` — ordering comes from `_category_.json`
files and each page's `sidebar_position` front matter. Add a page by dropping a Markdown
file in the right directory with front matter:

```md
---
sidebar_position: 3
title: My Page
description: One-line description.
---
```

## Deployment

The site deploys automatically to GitHub Pages on every push to `main` that touches
`website/**` (workflow: [`.github/workflows/docs.yml`](../.github/workflows/docs.yml)):

> https://havaianasdestruido.github.io/WindowsMovieMakerDecomp/

Deployment requires **Settings → Pages → Source: GitHub Actions** to be enabled on the
repository (one-time, by an admin).

Manual deployment from a workstation with `git push` rights:

```bash
npm run deploy   # uses docusaurus deploy (git push to gh-pages)
```

## Maintenance notes

- `onBrokenLinks: 'throw'` — the build fails on broken internal links. Keep relative
  links valid when moving/renaming pages.
- Mermaid diagrams (` ```mermaid ` blocks) are enabled via `@docusaurus/theme-mermaid`.
- Code highlighting includes `cpp`, `cmake`, `powershell`, `batch`, and `ini`.
- `package-lock.json` is committed so CI can use `npm ci` for reproducible installs.
