# WindowsMovieMakerDecomp — Website & Documentation Architecture

This repository uses a two-tier static website architecture for GitHub Pages:

1. **Primary Landing Page (Jekyll)**: Located at the repository root (`index.html`, `_layouts/`, `_includes/`, `assets/`, `_config.yml`). Serves `https://havaianasdestruido.github.io/WindowsMovieMakerDecomp/`.
2. **Documentation Portal (Docusaurus)**: Located in `website/`. Serves all comprehensive documentation under `/docs/` at `https://havaianasdestruido.github.io/WindowsMovieMakerDecomp/docs/`.

## Prerequisites

- **Jekyll**: Ruby ≥ 3.0, Bundler
- **Docusaurus**: Node.js ≥ 20 (Node 20/22 recommended)

## Running Docusaurus locally

```bash
cd website
npm install        # first time only

npm start          # dev server with hot reload → http://localhost:3000/WindowsMovieMakerDecomp/docs/
```

## Running Jekyll locally

```bash
bundle install     # first time only
bundle exec jekyll serve
```

## Production Build & Integration

The production build runs via GitHub Actions (`.github/workflows/docs.yml`):

1. **Jekyll Build**: Compiles root Jekyll site to `_site/` with baseurl `/WindowsMovieMakerDecomp`.
2. **Docusaurus Build**: Compiles `website/` into `website/build/` with baseurl `/WindowsMovieMakerDecomp/docs/`.
3. **Merge**: Copies `website/build/*` into `_site/docs/` and adds `.nojekyll`.
4. **Deploy**: Uploads `_site/` as the GitHub Pages artifact.

```bash
# Manual local build simulation:
bundle exec jekyll build --baseurl "/WindowsMovieMakerDecomp" --destination _site
cd website && npm ci && WMMR_DOCS_BASE_URL=/WindowsMovieMakerDecomp/docs/ npm run build && cd ..
mkdir -p _site/docs
cp -r website/build/* _site/docs/
touch _site/.nojekyll
```

## Documentation Structure

```text
website/
├── docs/                  # The documentation pages (MDX/Markdown)
│   ├── intro.md           # Introduction (slug: / -> /docs/)
│   ├── getting-started/   # Requirements, build, run, verify, troubleshoot
│   ├── architecture/      # Overview, app flow, module map, engine internals
│   ├── modules/           # One page per build target (29 modules)
│   ├── testing/           # Contract suite, harnesses, TODO audit
│   ├── methodology/       # Reconstruction, stub design, quirks, analysis
│   ├── tools/             # Build & analysis tooling
│   └── reference/         # Repo map, SDK compat, conventions, security, glossary, FAQ
├── src/
│   └── css/custom.css     # Theme & typography styles
├── static/img/            # Logo & favicon
├── docusaurus.config.js   # Site configuration (mounted at /docs/)
└── sidebars.js            # Autogenerated sidebar config
```

The sidebar is **autogenerated** from `docs/` — ordering comes from `_category_.json`
files and each page's `sidebar_position` front matter.

## Deployment & GitHub Pages Settings

The site deploys automatically on push to `main` via [`.github/workflows/docs.yml`](../.github/workflows/docs.yml):

> https://havaianasdestruido.github.io/WindowsMovieMakerDecomp/

Ensure **Repository Settings → Pages → Build and deployment → Source: GitHub Actions** is selected in GitHub settings.
